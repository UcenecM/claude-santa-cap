# Claude Santa Cap

A Claude Code mod that puts a Santa hat above the Claude mascot in the welcome logo.

<img src="screenshot.png" alt="Claude Code mascot wearing a Santa hat" width="520">

## Requirements

Claude Code 2.1.287 or later. The one-line shell install needs 2.1.292 or later.

## Install

At the prompt of a terminal session:

```
/plugin install santa-cap --marketplace UcenecM/claude-santa-cap
```

Confirm adding the marketplace, then pick a scope.

From a shell:

```
claude plugin install santa-cap --marketplace UcenecM/claude-santa-cap
```

This adds the marketplace without asking and installs for your user. Start Claude Code, or run `/reload-plugins` in an open session.

## Uninstall

At the prompt of a terminal session:

```
/plugin uninstall santa-cap
```

From a shell:

```
claude plugin uninstall santa-cap
```

If you installed it in a project or local scope, add `--scope project` or `--scope local`. Restart Claude Code afterwards and the hat is gone.
